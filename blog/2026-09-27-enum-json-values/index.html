Control Enum JSON Values

September 27, 2026·Source guide ↗

Keep API enum values separate from Dart enum names.

renameAll converts normal values to kebab case.

A value-level rename maps superAdmin to owner.

skip keeps legacyStaff valid in Dart but removes it from the JSON contract.

Dust generates both serialization and deserialization mappings.

The generated helpers reject the skipped value in either direction.

Docs used: Dust enum Serde and the product showcase enum example.
