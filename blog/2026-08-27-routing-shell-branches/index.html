Keep Tab Stacks Separate

August 27, 2026·Source guide ↗

Flutter’s navigation docs show why nested flows exist. Some routes should keep their own local stack.

Tabs have the same problem.

Open a product in Home. Switch to Orders. Open one order. Go back to Home. Most apps should still show the product page.

Dust Routing Shells split the job.

Use shell: for the shared layout. Use branch: for the tab stack that should be restored later.

The page stays a normal widget. The route keeps the navigation rule close to the screen.

Read the Dust Routing Shells guide.
