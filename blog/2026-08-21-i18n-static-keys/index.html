Keep Translation Keys Close to the UI

August 21, 2026·Source guide ↗

Translation keys drift when they live away from the screen.

With Dust, the key stays beside the widget. dust i18n build scans the static key, updates the ARB files, and refreshes the Flutter i18n bootstrap.

That keeps screen copy, fallback text, and translation files in the same workflow.

Read the Dust i18n guide.
