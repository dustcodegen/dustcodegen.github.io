02 / Capabilities

01

Data classes

Inspired by Rust derive. Generate equality, copyWith, toString, and model helpers.

02

JSON

Inspired by Serde. Generate JSON mapping with aliases, codecs, strict keys, and nested models.

Read the guide ↗
03

Validation

Inspired by Validate. Put field rules on the model and get path-aware errors back.

Read the guide ↗
04

HTTP clients

Inspired by Retrofit. Define a typed API interface and generate the request client.

05

Routing

Built for Flutter. Generate typed params, guards, shell routes, and result helpers.

06

State

Built for Flutter. Generate ViewModel args, state, and watch/read access.

03 / Workflow

  1. 01

    Annotate

    Add dust annotations to the Dart code you already own.

    @Derive(Serde()) class Article with _$Article {}
  2. 02

    Generate

    Run dust build. The Rust engine writes the generated Dart.

    $ dust build
  3. 03

    Use

    Call the generated helpers from normal Dart and Flutter code.

    Article.fromJson(json)
